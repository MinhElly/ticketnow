# Bàn giao TicketNow — 03/11/2026

Tiếp tục dự án tại `C:\Code\ticketnow`, PowerShell, trao đổi bằng tiếng Việt.
Branch hiện tại: `main`. Remote: `https://github.com/MinhElly/ticketnow.git`.

## Mốc đã hoàn thành

- Event Service: Spring Boot 4.0.0, Java target 17, MariaDB, Flyway V1;
  package horizontal, CRUD Venue/Event/TicketTier, validation, phân trang,
  ProblemDetail, Hibernate ddl-auto=validate.
- API Gateway: Spring Boot 4.1.2, Cloud 2025.1.4, WebFlux, cổng 8080;
  route /api/v1/events và /api/v1/venues (kể cả endpoint con) tới localhost:8081.
- Gateway và Event Service cùng kiểm tra JWT issuer
  http://localhost:8180/realms/ticketnow, audience ticketnow-api.
- Realm role Keycloak ánh xạ thành ROLE_ trong Event Service;
  organizerId lấy từ JWT sub. Chỉ organizer/admin được ghi sự kiện/hạng vé;
  chỉ chủ sở hữu hoặc admin được sửa/xóa và chỉ khi DRAFT.
- Venue ghi chỉ dành cho admin. Mọi API nghiệp vụ hiện vẫn yêu cầu đăng nhập.
- Danh sách sự kiện chỉ gồm PUBLISHED, ON_SALE, CLOSED, lọc trước phân trang.
  DRAFT/CANCELLED và hạng vé tương ứng chỉ chủ sở hữu/admin được đọc.
- Event cũ có organizerId=local-development không tự chuyển chủ sở hữu;
  admin vẫn quản lý được.

## Keycloak và database

- Compose: deploy/compose/docker-compose.yml; MariaDB host port 3307,
  Keycloak host port 8180, hai volume dữ liệu riêng.
- Database chính ticketnow_event; thông tin bí mật chỉ trong .env local.
  Database ticketnow_event_flyway cũ có thể vẫn tồn tại, không tự xóa.
- Realm ticketnow, client public ticketnow-postman, Authorization Code + PKCE S256.
  Callback: https://oauth.pstmn.io/v1/callback; password grant của client app tắt.
- User demo: admin01, organizer01, customer01; mật khẩu theo KC_DEMO_PASSWORD
  tại lúc import. admin01 khác tài khoản quản trị Keycloak realm master.
- Startup import bỏ qua realm đã tồn tại; đổi JSON/.env không cập nhật user cũ.
- registrationAllowed=false: chưa có tự đăng ký công khai hoặc /auth/register.
  Postman có luồng tùy chọn quản trị tạo user và gán customer qua Admin REST API.
- Không sửa migration V1 đã áp dụng; không chạy docker compose down -v.
